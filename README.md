# Diseño de Reconocimiento Facial para el Control de Acceso en UNICATÓLICA

Trabajo de grado de Ingeniería de Sistemas – Miguel Andrés Palomino Panesso y Juan David Rodríguez Papamija.

Prototipo en Python con OpenCV, face_recognition y SQLite para identificar personas,
asignar su categoría institucional y registrar cada evento de acceso.

## Instalación
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt

Las fotografías y vectores faciales no se incluyen en el repositorio por tratarse de
datos biométricos protegidos por la Ley 1581 de 2012.
